## RFC — S-05-B · Venta con descuento FEFO y comprobante interno
- RF que implementa: RF-011, RF-012, RF-013, RF-014
- Rol: implementation (backend)
- Alcance de este sprint: el sprint más delicado del proyecto. Registrar la venta en una sola transacción: validar, descontar del lote que vence primero, repartir entre lotes si hace falta, calcular IGV, reservar el correlativo y crear el comprobante en estado pendiente. **Explícitamente no**: el envío a SUNAT, que es S-06-B; el comprobante nace `PENDIENTE` y ahí se queda.
- Documentos relacionados: ADR-0003, ADR-0004, MIG-007, MIG-008, RNF-001, RNF-003, RNF-006
- Contratos que toca: docs/contratos/ventas.md (v1), docs/contratos/comprobantes.md (v1, sección de series)
- Estado: aprobado
- Aprobado por: Kevin Espíritu (kevinespiritu16@gmail.com) — fecha: 2026-08-19
