## RFC — S-06-F · Tablero de alertas y pantallas de reportes
- RF que implementa: RF-018, RF-019, RF-020, RF-021 (lado visible)
- Rol: implementation (frontend)
- Alcance de este sprint: el tablero que abre el sistema, con las alertas de vencimiento y stock bajo, y las dos pantallas de reportes. **Explícitamente no**: exportación a Excel o PDF, que ningún RF pide.
- Documentos relacionados: docs/frontend/experiencia.md, docs/frontend/integracion.md, docs/requisitos/actores-permisos.md
- Contratos que toca: docs/contratos/inventario.md (`GET /panel`), docs/contratos/ventas.md (reportes)
- Estado: aprobado
